# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | Edwaks: поиск товарных знаков |
| Репозиторий | edwaks.ru |
| Категория | публичный помощник поиска товарных знаков |
| Публичный адрес | https://edwaks.ru/ops/search |
| Аудитория | предприниматели, авторы брендов и специалисты по интеллектуальной собственности |
| Ценность | помогает провести первичную проверку обозначения по данным ФИПС и ВОИС |
| Основные сущности | обозначения, поисковые запросы, классы, результаты, справочные материалы и тарифы |
| Ключевые роли | Предприниматель, Маркетолог и Патентный специалист |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`форма поиска`, `просмотр совпадений`, `ориентирование по классам`, `источники ФИПС и ВОИС`, `справка`, `описание стоимости`, `подготовка к экспертной проверке`, `Предприниматель`, `Маркетолог`, `Патентный специалист`

## Заметки для индексации

Паспорт предназначен для каталогизации и поиска. Он не является технической спецификацией, договором или перечнем внутренних компонентов.
