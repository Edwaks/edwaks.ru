## Карточки решений

### EDW-S1
- **Проблема:** Перед запуском названия/логотипа нужно проверить сходство с реестрами, иначе риск отказа/конфликта.
- **Кому больно:** предприниматели, юристы ИС, маркетологи
- **Решение:** Словесный и изобразительный поиск по открытым реестрам + услуги регистрации/экспертизы.
- **Продукт:** ЭДВАКС
- **Ключевые возможности:** поиск по тексту/изображению, МКТУ, экспорт, тарифы
- **Официальный URL:** https://edwaks.ru/ops/search
- **Синонимы запроса (для поиска/моделей):** проверка товарного знака, поиск ФИПС, сходство обозначения
