# Сценарии использования — Edwaks: поиск товарных знаков

Типовые пользовательские сценарии без технических деталей внедрения.

## 1. Первое знакомство

**Контекст:** Новый пользователь из аудитории «предприниматели, авторы брендов и специалисты по интеллектуальной собственности» оценивает применимость продукта.

**Шаги:**
1. Открывает публичную страницу.
2. Сверяет назначение со своей задачей.
3. Изучает возможности: форма поиска, просмотр совпадений и ориентирование по классам.
4. Выбирает подходящую роль.
5. Переходит к предметному разделу.

**Результат:** Пользователь понимает границы продукта и может начать осмысленную работу.

## 2. Обработка одного объекта

**Контекст:** Участнику нужно выполнить законченное действие с сущностями: обозначения, поисковые запросы, классы, результаты, справочные материалы и тарифы.

**Шаги:**
1. Находит нужный объект.
2. Проверяет исходные сведения.
3. Определяет текущее состояние.
4. Выполняет доступное действие.
5. Проверяет наблюдаемый результат.

**Результат:** Объект получает понятное актуальное состояние, а результат доступен для продолжения процесса.

## 3. Передача следующей роли

**Контекст:** Работа требует участия нескольких людей с разной ответственностью.

**Шаги:**
1. Роль «Предприниматель» подготавливает контекст.
2. Роль «Маркетолог» уточняет предметные сведения.
3. Участник фиксирует результат этапа.
4. Роль «Патентный специалист» проверяет итог.
5. При необходимости объект возвращается с понятным замечанием.

**Результат:** Передача не требует пересобирать контекст из разрозненных сообщений.

## 4. Контроль набора объектов

**Контекст:** Ответственному участнику нужно увидеть общую картину и выбрать приоритет.

**Шаги:**
1. Открывает обзорный раздел.
2. Сужает список по предметному признаку.
3. Сравнивает состояния.
4. Выбирает объект, требующий внимания.
5. Переходит в карточку и принимает следующее решение.

**Результат:** Общий обзор превращается в конкретное проверяемое действие.

## 5. Возврат к незавершённой работе

**Контекст:** Пользователь продолжает процесс после перерыва.

**Шаги:**
1. Возвращается в продукт.
2. Находит ранее затронутый объект.
3. Сверяет актуальное состояние.
4. Восстанавливает следующий шаг по видимому контексту.
5. Завершает или передаёт этап.

**Результат:** Работа продолжается без потери предметного смысла.
